The rsutil module

The `rsutil` module is the core of the package. It provides various utility functions and base classes that can be used to process and analyze atomic structures, perform data processing, and handle other aspects of scientific computing.

This module provides a Python wrapper for the process_lattice Fortran routine from the rsutil shared library.

Attributes

lib_filenameOptional[str]

The filename of the rsutil shared library, determined dynamically.

lib_pathstr

The full path to the rsutil shared library.

The loaded rsutil shared library.
