The `viz` submodule
-------------------

The **`viz`** submodule contains visualization tools for RS-utils. It provides
interactive 3D visualization of atomic structures, magnetic properties, and
crystal lattices using PyVista, as well as plotting of RS-LMTO DOS output files
with Matplotlib.

Key Features
~~~~~~~~~~~~

- Interactive 3D visualization of crystal structures
- Magnetic moment (spin) vectors and glyphs
- Bond visualization with adjustable styling
- Periodic lattice rendering and cluster views
- RS-LMTO input support: ``lattice.nml``, ``input.nml``, and ``clust`` files
- CPK color schemes for element visualization
- Total and species/site projected DOS plots with spin and layout options

Usage Examples
~~~~~~~~~~~~~~

From the command line:

.. code-block:: bash

    # Plot DOS files already present in a calculation directory
    rsutil viz dos /path/to/calc --fermi 0.7 --output dos.png

    # Select species and disable the default filled overlay style
    rsutil viz dos /path/to/calc --species Ni-S Ni-S-1 --layout stack --no-fill

    # Visualize lattice structure
    rsutil --lattice --data /path/to/data
    rsutil viz lattice /path/to/data

    # Visualize cluster definition
    rsutil --clust --data /path/to/data
    rsutil viz clust /path/to/data

``rsutil dos`` computes DOS from a Hamiltonian, while ``rsutil viz dos``
plots DOS files (such as ``magneticdos.out`` and ``*_dos.out``) generated by
an RS-LMTO run. DOS plotting is available with ``pip install 'rsutil[bands]'``;
the interactive structure viewer uses ``pip install 'rsutil[visualization]'``.

From Python code:

.. code-block:: python

    from rsutil.viz.rs_visualizer import rs_visualizer

    # Launch interactive visualizer for lattice
    rs_visualizer(data_dir='/path/to/data', clust=False)

    # Launch visualizer for clust file
    rs_visualizer(data_dir='/path/to/data', clust=True)
